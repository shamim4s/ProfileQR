How Online QR works

  1. Choose Online QR in the generator.
  2. Enter the profile details and your GitHub repository credentials.
  3. The generator creates the public profile URL automatically.
  4. Four files are published inside profiles/<id>/.
  5. The QR contains the profile URL, so scanning opens the profile page.
  6. The profile page lets visitors call, email, visit the website, or save the contact.
